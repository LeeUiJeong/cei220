# CEI 220회 실험 참조 구현 — 배포용 사본

논문 실험의 핵심 코드와 기존 결과를 보존하면서, 다른 컴퓨터에서 사용할 수 있도록 안내문과 감사 노트북 경로를 정리한 사본입니다.

**프로젝트 코드와 소프트웨어 사용 문서에는 MIT 라이선스를 적용했습니다.** 저장소 주소는 [LeeUiJeong/cei220](https://github.com/LeeUiJeong/cei220)입니다.

## 시작하기

1. Python 3.10 전용 환경을 준비합니다.
2. [영문 README](README.md)의 CPU 설치 절차 또는 기존 `environment.yml`의 GPU 환경을 선택합니다.
3. 프로젝트 루트에서 `python -m pytest -q`로 오프라인 테스트를 수행합니다.
4. `python tools/check_distribution.py`로 보존 대상 파일의 해시를 확인합니다.
5. `python scripts/run_all.py --config configs/experiment_220.yaml --dry-run`으로 220회 실행 계획을 확인합니다.

오프라인 테스트는 합성 이미지와 임시 폴더를 사용합니다. 실제 데이터셋을 다운로드하거나 논문의 220회 학습을 다시 수행하지 않습니다.

## 목적에 따른 사용

- 기존 논문 결과 확인: `reference_results/cei_220_reference_v1/`을 읽습니다.
- 실제 데이터의 축소 실행: `configs/smoke.yaml`을 사용합니다. CIFAR-10 다운로드와 7회·각 1에폭 학습이 발생합니다.
- 전체 프로토콜 실행: `configs/experiment_220.yaml`을 사용합니다. 학습·평가 220회가 수행됩니다.
- 저장된 모델의 사후 감사: [감사 안내](audit/README.md)에 따라 원본 실행별 모델 파일을 별도로 준비합니다.

전체 파이프라인은 환경 확인, 데이터 준비, 실행, 집계, 자동 검증을 수행합니다. 독립 해시 감사와 단위 테스트는 별도 절차입니다. 기본 실행은 완료된 실행을 건너뛰며, `--overwrite`는 기존 실행별 산출물을 삭제하므로 주의해야 합니다.

## 원본 보존과 해석 범위

새 실험은 `results/`, 과거 논문 결과는 `reference_results/`로 구분했습니다. 기존 CSV·JSON의 수치와 해시값은 수정하지 않았습니다. 당시 컴퓨터의 절대 경로는 원본 연결 정보이며 다른 컴퓨터의 실행 경로가 아닙니다.

이 사본에는 실행별 모델 상태 파일, 체크포인트, 전체 상세 로그와 원본 데이터셋이 없습니다. 따라서 이 사본만으로 원래 220개 모델 파일을 다시 감사할 수 없습니다. 전체 원본 결과의 별도 배포·접근 방법은 아직 정해지지 않았습니다.

- 실제 로컬 검증 범위: [검증 기록](docs/VALIDATION.md)
- 배포본 변경 내역: [RELEASE_NOTES.md](RELEASE_NOTES.md)
- 원본 파일별 SHA-256: [출처 목록](docs/SOURCE_PROVENANCE.json)
- 공개 전 저자 확인 사항: [체크리스트](docs/PUBLICATION_CHECKLIST.md)

합성 데이터 테스트와 설치 확인은 기능 점검입니다. 논문의 실험 결과를 새 환경에서 다시 입증한 것으로 해석하지 않습니다.
